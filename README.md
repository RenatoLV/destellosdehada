# Destellos de Hada

Repositorio de las aplicaciones y servicios de la tienda.

- `web/`: boutique pública de joyas, perfumes y ropa, construida con Expo Router y desplegada en Firebase.
- `mobile/`: aplicación móvil de administración, inventario y ventas.
- `supabase/`: migraciones y funciones del backend utilizado por la aplicación móvil.

Cada aplicación conserva sus propias dependencias e instrucciones en su carpeta.
